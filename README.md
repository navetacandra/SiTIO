# SiTIO

> Proyek akhir semester Teknik Informatika PNJ 2026 (Semester 3). Dibuat dengan berkolaborasi antar anggota kelompok. Pembuatan menggunakan PHP Native dan basis data PostgreSQL.

SiTIO merupakan akronim dari Sistem Terpusat International Office, proyek ini dibuat dengan tujuan membangun
sebuah platform berbasis web untuk layanan internasional PNJ. Lingkup dari proyek ini adalah pengajuan surat rekomendasi
untuk keluar negeri oleh mahasiswa, pengajuan Surat Persetujuan Setneg bagi dosen/struktural untuk melakukan perjalanan dinas luar
negeri, pengajuan pembuatan/permit paspor dinas dosen/struktural, pengajuan surat jaminan/lainnya dari eksternal (luar negeri)
untuk ke PNJ, serta pengajuan tiket bantuan.
